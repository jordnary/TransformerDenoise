# 去噪改进实验结果

## 验证阶段

本轮按预先保存的实验计划执行。以下选择在读取外部测试图进行本轮评估之前完成，未使用测试图的干净目标选择超参数或检查点。

| 方案 | 数字 PSNR / dB | 灰度 PSNR / dB | 结构 PSNR / dB | 三域平均 L1 |
| --- | ---: | ---: | ---: | ---: |
| 初始化检查点 | 25.7232 | 24.5586 | 25.9336 | 0.027175 |
| 继续训练 | 25.7681 | 25.0265 | 26.2596 | 0.025067 |
| 结构增强 | 25.8004 | 25.0423 | 26.5045 | 0.025319 |
| 结构增强＋重叠修正 | 25.8244 | 25.0656 | 26.5311 | 0.025286 |

三组均选择第 12 轮，均满足数字验证 PSNR 下降不超过 0.20 dB 的限制。最终选中继续训练对照组，其三域平均 L1 最低。仅结构增强在结构域上的 PSNR 有改善；重叠修正进一步小幅改善 PSNR，但两组综合 L1 均未超过继续训练对照。不能据此声称结构改动整体优于原模型。

新增结构增强和重叠修正保留为可复现实验选项，未替换原有默认模型。选中方案随后在全部 60,000 张 MNIST 训练图上固定训练 8 轮；不再用原验证集选优。

## 最终评估

所有主结果均为单次前向计算后投影至 [0,1]。新旧模型使用相同含噪输入；测试目标逐像素核对了原始文件，未修改或缩放原图。

| 方案 | 424242 / dB | 424243 / dB | 424244 / dB | 平均 / dB |
| --- | ---: | ---: | ---: | ---: |
| 旧模型（60,000 张） | 18.9077 | 18.6320 | 19.2350 | 18.9249 |
| 验证选定后全量训练（60,000 张） | 18.8624 | 18.5964 | 19.2576 | 18.9055 |
| 高斯平滑基线 | 19.4873 | 19.1973 | 19.1728 | 19.2858 |

主噪声种子下，MNIST 测试集平均 PSNR 从 25.8043 dB 提高到 25.8470 dB；但外部图像从 18.9077 dB 降至 18.8624 dB。三个外部噪声种子的平均变化为 -0.0194 dB。此次继续训练没有解决外部图像过度平滑的问题。

## 冻结候选的补充诊断

主测试完成后，为检验结构改动在目标图像上的实际表现，额外评估三组已经冻结的 55,000 张训练数据候选。三组额外训练预算相同，均按验证集固定为第 12 轮。没有重新训练、调参或根据这些测试结果重新选择主方案。这属于事后诊断，与 60,000 张全量训练模型的比较不能单独用来归因结构改动。

| 冻结候选 | 424242 / dB | 424243 / dB | 424244 / dB | 平均 / dB |
| --- | ---: | ---: | ---: | ---: |
| 继续训练 | 18.8732 | 18.6134 | 19.2422 | 18.9096 |
| 结构增强 | 18.9207 | 18.6406 | 19.2959 | 18.9524 |
| 结构增强＋重叠修正 | 18.9169 | 18.6380 | 19.3093 | 18.9547 |

结构增强及重叠修正相对旧模型的三噪声平均增益分别约为 0.028 dB、0.030 dB；重叠修正相对仅结构增强的平均增益约为 0.002 dB。这些差距很小，且两者仍低于高斯平滑基线。

## 图像评价与处置

并排检查发现：新旧结果的大尺度明暗和主要轮廓相近，左侧细线与交叉结构仍大面积消失，未出现有说服力的视觉改善。结构增强与重叠修正没有明显修复这些细节。

因此保留旧模型作为默认，所有新权重保留为实验候选。这轮实验支持“单纯延长训练或采用当前这组 MNIST 增强，尚不足以解决自然图像的分布差异”，不能推断全部结构增强或 Transformer 架构均无效。仅有一张自然图像和三个噪声种子，也不足以宣称普遍泛化改善。

## 核验与复现

- 训练损失始终为 L1；噪声标准差固定为 50/255，含噪输入不裁剪。
- 仅使用 MNIST 训练数据及其增强，无外部预训练网络；中间层无卷积。
- 完整 denoise Python 实现共 775 行；11 项契约测试通过。
- 共 16 份评估输出通过独立复算，包括每类首样本选择、固定噪声及逐图与汇总指标；外部 GT 均逐像素等于原图。
- 旧模型复评结果与此前保存的主结果一致；默认权重未覆盖。
- 三组训练加全量阶段共 44 轮。主方案选择在本轮外部测试前已记录并提交。

主实验命令见 README。补充诊断可用 python -m denoise.evaluate 分别加载三个实验检查点，固定外部种子为 424242、424243、424244，并启用 --project-output；再使用 python -m denoise.audit 复算各输出。

```powershell
foreach ($arm in @('control', 'structure', 'refinement')) {
    foreach ($i in 0..2) {
        $result = "outputs/experiment/diagnostic/$($arm)_$($i + 1)"
        python -m denoise.evaluate --checkpoint "runs/experiment/$arm/model.pt" --external assignment/test.png --seed (20261029 + $i) --external-seed (424242 + $i) --project-output --output $result
        python -m denoise.audit $result
    }
}
```

完整数值见 [experiment_metrics.json](experiment_metrics.json)。本地生成图包括 outputs/experiment/comparison.png、outputs/experiment/diagnostic_comparison.png 和各目录的数字对比图，生成产物不提交至 Git。
